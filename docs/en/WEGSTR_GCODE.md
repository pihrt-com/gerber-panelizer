# Wegstr G-code

This document describes the exact G-code subset generated by Gerber Panelizer for Wegstr. It is not a complete list of every command that a Wegstr controller may support. The output follows the sample programs supplied with Wegstr 3.2.0.

## Files and operation order

The export creates a ZIP with these text programs:

1. `01-copper-isolation.txt` — copper trace and pad isolation.
2. `02-drill.txt` — drilling when enabled and drill hits are present.
3. `03-board-outline.txt` — outline cutting when explicitly enabled.

Run the programs in this order. Outline cutting is disabled by default because the exporter does not yet generate holding tabs or multiple depth passes.

## Coordinate system

- Units are millimetres (`G21`).
- Coordinates are absolute (`G90`).
- X0 Y0 is the top-left corner of the machine work area.
- X increases to the right and Y is negative downward, for example `X25.000Y-40.000`.
- Z0 is the material surface, safe Z is positive, and cutting depths are negative.
- Bottom output uses the mirror policy selected in Settings; preview and export use the same transformation.

## Generated commands

| Command | Meaning in the generated output |
| --- | --- |
| `N...` | Line numbers increasing by ten. |
| `( ... )` | Program, material, or tool comment. |
| `G00` | Rapid move in X, Y, or Z. |
| `G1` | Cutting move or plunge. |
| `G17` | XY working plane. |
| `G21` | Metric units. |
| `G40` | Cancel controller cutter compensation; outline compensation is calculated by the exporter. |
| `G43 ... Hn` | Enable the selected tool-length offset. |
| `G49` | Cancel a previous tool-length offset during initialization. |
| `G71 G91.1` | Initialization commands preserved from the supplied Wegstr samples. |
| `G80` | Cancel an active canned cycle. |
| `G90` | Absolute coordinates. |
| `G94` | Feed in millimetres per minute. |
| `Tn M06` | Select and change the tool. |
| `S... M03` | Set spindle speed and start the spindle. |
| `M09` | Turn coolant off before completion. |
| `M30` | End the program. |
| `%` | Final program delimiter. |

The exporter does not generate inch mode `G20`, relative coordinates `G91`, arcs `G02`/`G03`, canned drilling cycles `G81`/`G83`, or `M05`. Program completion follows the supplied Wegstr samples: return to safe Z, return to X0 Y0, `M09`, `M30`, and `%`.

## Copper-isolation example

```gcode
( Gerber Panelizer - copper isolation )
( for Wegstr from Gerber Panelizer )
N120G00G21G17G90G40G49G80
N130G71G91.1
N140T1M06
N150 (30 deg. spiral carbide engraving bit)
N160G00G43Z2.000H1
N170S12000M03
N180G94
N190X0.000Y0.000F170.0
N200G00X12.450Y-25.300Z2.000
N210G00Z0.000
N220G1Z-0.080F170.0
N230G1X13.100Y-25.300
N240G1X13.100Y-26.000
N250G1X12.450Y-25.300
N260G00Z2.000
```

An isolation path is not a simple outline of every Gerber segment. The exporter first unions overlapping supported traces and pads into one area, then offsets that area's boundary by the configured tool-centre clearance.

## Drilling example

```gcode
N140T1M06
N150 (drill 0.8 mm)
N160G00G43Z2.000H1
N170S12000M03
N180G94
N190G00X18.000Y-32.000Z2.000
N200G00Z0.000
N210G1Z-1.800F170.0
N220G00Z2.000
```

Each drill diameter receives its own tool number. Before running the program, confirm that the tool numbers and `H` length offsets match the tools actually loaded in the machine.

## Supported input geometry

Copper isolation converts straight traces with circular apertures and circle, rectangle, or obround flashes. Overlapping objects are geometrically unioned. Gerber arcs, regions, macros, and non-circular trace apertures are never converted silently: an unsafe file stops the export or the unsupported object is skipped with a warning in Details.

An outline must be a closed path made from straight segments. The exporter offsets it by half of the configured cutter diameter. Drilling is read from Excellon and grouped by tool diameter.

## Safe first test

1. Confirm the work-area size, X0 Y0 origin, and axis orientation.
2. Verify safe Z, cutting depths, feeds, spindle speed, tool numbers, and length offsets.
3. Open every TXT program in the controller and inspect the complete path.
4. Perform an air cut with the tool raised above sacrificial material.
5. Start with a small panel and enable outline cutting only after isolation and drilling have been verified.

The defaults are only a starting profile based on the supplied samples. They do not guarantee safe parameters for a particular tool, material, or machine.
